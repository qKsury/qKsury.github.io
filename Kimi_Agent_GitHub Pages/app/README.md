# Ksury — личный ML-сайт

Статический сайт для GitHub Pages в тёмном кинематографичном стиле с зернистыми изображениями и интерактивными деталями:

- `index.html` — главное ML-портфолио: структурированные личные данные, расширенный стек со значками и ссылками на документацию;
- `music.html` — коллекция из 28 альбомов, меняющаяся витрина, топ-10 за последний месяц и плеер фрагментов;
- `characters.html` — страница «Аура»: четыре коллекционные карточки с локальными изображениями, английскими цитатами и объёмным наклоном при наведении;
- `assets/tech-icons.svg` — локальные логотипы и символы технологий;
- `data/albums.json` — содержимое музыкальной коллекции;
- `data/top-tracks.json` — демонстрационный чарт, который заменяется данными Last.fm;
- `scripts/update_lastfm.py` — получение статистики и обложек без передачи API-ключа в браузер;
- `.github/workflows/pages.yml` — публикация сайта и ежедневное обновление чарта.

Сборка и зависимости не нужны. Это обычные HTML, CSS и JavaScript.

## Локальный просмотр

Не открывай `index.html` двойным щелчком: браузер может запретить загрузку JSON и SVG-значков с локального диска. Запусти в папке проекта:

```bash
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`.

## Публикация на GitHub Pages

1. Создай **публичный** репозиторий и загрузи в него все файлы проекта, включая скрытую папку `.github`.
2. Ветка должна называться `main`. Если у тебя `master`, переименуй её или измени ветку в `.github/workflows/pages.yml`.
3. Открой **Settings → Pages** и в поле **Source** выбери **GitHub Actions**.
4. Открой вкладку **Actions**, дождись завершения workflow **Publish GitHub Pages and refresh Last.fm**.
5. Адрес будет вида `https://USERNAME.github.io/REPOSITORY/`. Для репозитория с именем `USERNAME.github.io` сайт откроется прямо по `https://USERNAME.github.io/`.

Пока Last.fm не настроен, workflow всё равно публикует сайт с демонстрационным чартом.

## Подключение настоящего топ-10 Last.fm

1. Зарегистрируйся на [Last.fm](https://www.last.fm/) и включи скробблинг прослушиваний. Для Spotify подключение настраивается в профиле Last.fm.
2. Создай API-аккаунт на [странице Last.fm API](https://www.last.fm/api/account/create) и скопируй **API key**. Shared secret для этого сайта не нужен.
3. В репозитории открой **Settings → Secrets and variables → Actions**.
4. На вкладке **Secrets** создай секрет:
   - имя: `LASTFM_API_KEY`;
   - значение: API-ключ Last.fm.
5. Публичный логин `qKsury` уже указан в workflow; при смене аккаунта отредактируй значение `LASTFM_USERNAME` в `.github/workflows/pages.yml`.
6. Открой **Actions → Publish GitHub Pages and refresh Last.fm → Run workflow**.

После успешного запуска подпись «Демо-данные» исчезнет. Дальше чарт будет обновляться ежедневно по расписанию. Период `1month` соответствует [официальному методу `user.getTopTracks`](https://www.last.fm/api/show/user.getTopTracks).

Если API или сервис обложек временно недоступен, публикация не падает: сайт сохраняет предыдущий JSON, а предупреждение появляется в логе workflow.

## Как заменить содержимое

### Имя и личные данные

Отредактируй тексты прямо в `index.html`. Личные данные собраны в блоке `profile-coordinates`, а технологии размечены ссылками `tech-item`. Основные стили находятся в `assets/home-progressive.css`.

### Фотография

На главной используется обработанная фотография `assets/portrait-artem.webp`. Для замены сохрани новое изображение под тем же именем или измени путь в `src` внутри блока `subject-arch` в `index.html` и обнови `alt`.

### Любимые альбомы

Измени массив `albums` в `data/albums.json`. Пример записи:

```json
{
  "artist": "Исполнитель",
  "title": "Название альбома",
  "year": 2024,
  "cover": "./assets/covers/my-album.webp",
  "mood": "для ночной прогулки",
  "note": "Пара личных предложений об альбоме."
}
```

Положи свою квадратную обложку в `assets/covers/` и укажи путь в `cover`. Ссылка Spotify формируется автоматически как поиск по исполнителю и названию.

### Изображения и цитаты персонажей

Изображения хранятся в `assets/characters/` под именами `arthas.webp`, `luke.webp`, `andy.webp` и `saul.webp`. Для замены сохрани новый файл под тем же именем или измени путь в `characters.html`. Цитаты находятся в элементах `blockquote`; стили коллекции — в `assets/aura-progressive.css`, наклон карточек — в `src/aura.js`. Источники изображений перечислены в `CREDITS.md`.

### Отключить демонстрационный ручной чарт

После настройки Last.fm ничего удалять не нужно: workflow сам перезапишет `data/top-tracks.json` во время публикации. Если автоматическая статистика больше не нужна, удали шаг **Refresh monthly Last.fm chart** из workflow и редактируй JSON вручную.

## Технические ограничения

- Это статический сайт: серверной части, аккаунтов и базы данных нет.
- Данные Last.fm обновляются при запуске GitHub Actions, а не в реальном времени.
- Фрагменты треков доступны только там, где их возвращает публичный поиск Apple iTunes. Кнопка воспроизведения не показывается без доступного фрагмента.
- Внешние шрифты Google Fonts, ссылки Spotify и аудиофрагменты требуют подключения к интернету. Значки технологий хранятся локально и отдельной сетевой загрузки не требуют.
