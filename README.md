# qKsury.github.io

Личный сайт с ML-портфолио, коллекцией альбомов и страницей с цитатами персонажей.

## Разделы

- **Главная** — информация обо мне, стек технологий и контакты.
- **Альбомы** — 28 альбомов, меняющаяся подборка и аудиофрагменты.
- **Аура** — коллекция карточек с изображениями и цитатами.
- **Топ-10** — наиболее прослушиваемые треки за последний месяц по данным Last.fm.

## Технологии

HTML, CSS и JavaScript без фреймворков и сборки. Данные хранятся в JSON. Python-скрипт и GitHub Actions обновляют музыкальный чарт и публикуют сайт на GitHub Pages.

## Структура проекта

- `index.html` — главная страница.
- `music.html` — музыкальная коллекция.
- `characters.html` — страница «Аура».
- `assets/` — стили и изображения.
- `src/` — JavaScript.
- `data/` — альбомы и музыкальный чарт.
- `scripts/update_lastfm.py` — обновление данных Last.fm.
- `.github/workflows/pages.yml` — публикация сайта и обновление чарта.

## Локальный запуск

В корне проекта выполнить: `python3 -m http.server 8080`

Затем открыть: `http://localhost:8080`
